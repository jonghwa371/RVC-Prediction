# ORIGIN — FTA Origin Risk Dashboard

## 실행
Python 3.10+ 환경에서:

```bash
pip install -r requirements.txt
streamlit run app.py
```

자동으로 브라우저가 열립니다. 원본 B 데이터(`data/scenario_B.csv`)가 포함되어 있으므로 별도 업로드는 필요하지 않습니다.

## 사용 방법
1. 왼쪽에서 제품 또는 전체 원재료를 선택합니다.
2. BOM 표에서 제품당 원재료 투입비용과 원산지 지위를 편집합니다.
3. FOB를 직접 입력합니다. 현재 VNM과 RVC는 즉시 변경됩니다.
4. 예측 개월과 반복 횟수를 정한 뒤 ARMA 예측 버튼을 누릅니다.
5. 예상 RVC, 90% 예측구간, RVC 40% 미충족 확률, 원재료별 기여도를 확인합니다.

## 계산상 전제 및 주의
- 원재료별 원화 로그수익률(`krw_log_return_fx_100pct`)을 ARMA(0,0), AR(1), MA(1), ARMA(1,1)로 적합하고 AICc 최소 후보를 선택합니다.
- 달력상 연속된 최근 관측 구간만 사용합니다. 결측 월을 건너뛰어 연속 관측으로 취급하지 않습니다.
- 미래 가격 변화는 ARMA 예측 평균 + 과거 적합 잔차의 독립 재표본추출로 모의 생성합니다. 잔차의 시계열 의존성, 원재료 간 상관관계, 모수 추정 불확실성은 완전히 반영하지 않습니다.
- `bom_base_cost_krw`는 제품당 원재료 투입비용이며 시장가격/실제 BOM으로 검증된 값이 아닙니다.
- 원산지 지위는 사용자가 확인해야 하며, `원산지 확인`은 실제 증빙과 협정별 원산지 요건을 충족했다는 의미로 사용해야 합니다. 데모 데이터는 법적 판단이 아닙니다.
- 미확인 및 비원산지재료는 분석상 VNM에 포함합니다.
- RVC=(FOB−VNM)/FOB×100. 40%는 분석용 가정이며 실제 적용 협정의 품목별 기준을 반드시 확인해야 합니다.
- 결측 가격의 재료가 VNM에 포함되어 있으면 미래 위험 확률을 계산하지 않고 결측을 명시합니다.
- 원본의 일부 원재료는 대체·프록시 데이터일 수 있습니다. 실거래 예측 정확도와 법적 FTA 원산지 충족을 보증하지 않습니다.

## GitHub / Streamlit Community Cloud 배포
1. 이 ZIP의 **내용물 전체**를 새 GitHub 저장소의 최상위(root)에 업로드합니다. ZIP 파일만 올리지 마세요.
2. https://share.streamlit.io/ 에 GitHub 계정으로 로그인하고 **Create app** → **Deploy a public app from GitHub**를 선택합니다.
3. 저장소와 브랜치(`main`)를 선택하고 **Main file path**를 `app.py`로 지정합니다.
4. 배포 후 발급된 `*.streamlit.app` URL을 공모전 제출 자료에 기재합니다.
5. 무료 앱은 비활성 시 휴면할 수 있으니 제출 직전과 심사 기간에 접속 테스트를 권장합니다.

이 저장소에는 데모용 `data/scenario_B.csv`가 포함되어 있습니다. 실제 기업의 비공개 BOM/가격 데이터는 공개 저장소에 업로드하지 마세요.
